# 系统管理模块 - 单元测试用例设计文档

##  测试范围

### 员工管理 (Staff Management) {#员工管理-staff-management .标题3}

- 员工信息的增删改查
- 员工状态管理（在职/离职/禁用）
- 部门分配
- 数据导入导出

### 部门管理 (Department Management)

- 部门的层级结构管理（支持添加子部门）
- 部门信息的维护
- 数据导入导出

### 文档管理 (Document Management)

- 文件上传
- 文件下载
- 文档信息的增删改查
- 数据导入导出

### 考勤记录管理 (Attendance Management)

- 考勤记录的增删改查
- 考勤状态判定（正常/迟到/早退/缺勤/请假/调休）
- 按员工和日期查询
- 数据导入导出

### 请假申请管理 (Staff Leave Management)

- 请假申请的增删改查
- 请假类型（个人假/产假/病假/婚假/回乡假/陪产假/调休）
- 请假流程（申请/审核/批准/驳回/取消）
- Activiti工作流集成
- 冲突检测（同一员工不能有多个待审核请假）
- 数据导入导出

### 加班记录管理 (Staff Overtime Management)

- 加班记录的增删改查
- 加班类型判定（工作日1.5倍/休息日2倍/法定假日3倍）
- 加班时长计算
- 加班费计算
- 按员工和日期查询
- 调休管理
- 数据导入导出

### 薪资管理 (Salary Management)

- 员工月薪资计算与管理
- 薪资组成：基础工资、加班费、补贴、奖金
- 自动扣款计算：迟到、早退、旷工、休假扣款
- 薪资明细查看
- 月薪资报表导出（Excel）

### 五险一金管理 (Social Security Management)

- 社保和公积金的基数设置
- 个人和企业缴纳比例配置
- 自动计算个人和企业缴纳金额
- 参保城市管理（不同城市可配置不同标准）
- 五险一金报表导出

### 扣款管理 (Deduction Management)

- 薪资扣除规则配置
- 扣款类型管理
